# dictionary

## 目的

维护 `app/TOEFL_abridged.txt` 的解析与查询，为词卡提供音标、词性、释义。

## 行格式

```
abate             [ə'beit]              vt. 缓和,减弱,减少,废除 vi. 缓和,减弱,减少
```

- 第一列：单词；
- `[...]`：音标，沿用文件原写法；
- 其后：`词性. 释义`，可以有多段（如 `vt.` + `vi.`）。

## 解析规则

1. 按行解析，空行跳过；
2. 音标括号容错（文件里 `subdue [səb'dju:]]` 多了一个 `]`）；
3. 词性缩写集合：`n. v. vt. vi. adj. adv. a. ad. prep. conj. pron. aux. art. num. int. pl.`；
4. 连续多个词性（如 `vt. vi. 邻接`）合并为 `vt./vi.`；
5. 统一小写查询；查不到返回 null，由调用方回退到模型字段。

## 验收用例

- 词条总数 1320；
- `abate` → 两个义项；`adjoin` → `vt./vi.`；`subdue` → 正常解析；
- 不存在的词 → null；
- 词典命中时，接口返回的 `ipa` 为 `[...]` 形式且带 `senses`。

## 已知坑

- 文件里的释义偶有不准（如 `mitigate` 写成“镇静”），不要据此改解析；
- 音标不是 IPA，展示时保留原样。
